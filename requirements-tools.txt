# QEncode leaderboard / analysis tooling.
# NOT part of the pinned benchmark environment — install it in addition:
#
#     pip install -r requirements-v4.txt -r requirements-tools.txt
#
# Why this is a separate file rather than more lines in requirements-v4.txt:
#
# The reproducibility guard in scripts/generate_entry_v4.py parses every
# `name==version` pin out of requirements-v4.txt and refuses to write an entry
# unless each one is importable at exactly that version. That strictness is the
# point — an entry must be reproducible from what it records.
#
# The benchmark pipeline imports none of the packages below. Pinning them in
# requirements-v4.txt would make a missing or mismatched pandas block entry
# generation entirely, and would write irrelevant dependencies into the recorded
# environment of every entry. The benchmark stack stays minimal and about the
# science; tooling dependencies live here.
#
# Used by:
#   scripts/generate_leaderboard.py  pandas (required)
#                                    yaml   (optional: baseline marking)
#   src/qencode/attestation.py       cryptography (Ed25519 signature verification),
#                                    reached transitively by both leaderboard scripts
#
# Not listed here on purpose: qiskit is imported only by
# src/qencode/dataset_loader.py, which is not on the import path of the leaderboard
# scripts, so it is not required to run the tooling.
#
# Verified on the pinned stack (Python 3.11): installing these leaves numpy 2.2.6
# and scipy 1.13.1 untouched, and `python scripts/generate_leaderboard.py --help`
# and `scripts/assign_trust_levels.py --help` both run.

pandas==2.2.3
PyYAML==6.0.2
# 43.0.1 carried 10 published advisories: X.509 path building, DNS name constraint
# enforcement, and the OpenSSL bundled in the wheels. None were reachable from this
# repository -- attestation.py uses only Ed25519 sign/verify and PEM key loading, and
# nothing here parses X.509 or terminates TLS -- but there is no reason to keep a pin
# with known advisories when the fix costs nothing. 50.0.1 is advisory-free; 49.0.0
# still carries two. It requires only cffi, so the pinned science stack is untouched,
# and it was checked against the exact API attestation.py uses: keygen, PEM round-trip,
# sign, verify, and rejection of a tampered payload.
cryptography==50.0.1
